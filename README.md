# Supplement Sales Analysis Dashboard

## 📊 Project Overview
This project analyzes supplement sales data using Microsoft Excel to understand product performance, sales trends, and regional sales patterns.

## 🛠️ Tools Used

* Microsoft Excel
* PivotTables
* PivotCharts
* Excel Formulas
* Data Analysis
* Dashboard

## 📌 Key Analysis

* Product Performance Analysis
* Sales Trend Analysis
* Regional Sales Analysis
* Key Sales Metrics
* Dashboard Visualization

## 🎯 Objective

The objective of this project is to analyze supplement sales data and create an interactive Excel dashboard to present sales performance and business insights in an easy-to-understand format.
